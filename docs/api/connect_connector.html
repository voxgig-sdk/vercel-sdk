create

POST /v1/connect/connectors

Operation ID: createConnector.

Authentication: bearer token (bearerToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | teamId | query | string | No | The team ID that scopes the request. Do not send it with slug. If both are omitted, Vercel uses the team associated with the token or the authenticated user's default team. The request returns 401 if no team can be selected. | | slug | query | string | No | The team slug that scopes the request. Do not send it with teamId. If both are omitted, Vercel uses the team associated with the token or the authenticated user's default team. The request returns 401 if no team can be selected. |
