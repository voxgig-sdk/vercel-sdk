create

POST /api-keys

Operation ID: createApiKeys.

Authentication: not required.

Request body

application/json

Property Type Required Description
aiGatewayQuota object No Optional AI Gateway quota configuration for the API key.
aiGatewayQuota.alertThresholds array of enum: 50, 75, 100 No Spend percentages (a subset of [50, 75, 100]) at which to send a spend alert.
aiGatewayQuota.includeByokInQuota boolean No Whether to include BYOK (Bring Your Own Key) usage in the quota.
aiGatewayQuota.limitAmount number Yes The quota limit amount.
aiGatewayQuota.refreshPeriod enum: daily, weekly, monthly, none No How often the quota refreshes.
expiresAt number No The API key's expiration, expressed as a UNIX timestamp in milliseconds.
metadata object No Optional generic metadata for the API key. The accepted shape depends on the key's purpose and is validated on creation; for ai-gateway keys this accepts environment.
name string No An optional name for the API key.
projectId string No An optional project to restrict the API key to.
purpose string Yes The API key's purpose, which restricts how it can be used.

200: Successfully created an API key

application/json

Property Type Required Description

apiKey.partialKey string Yes The last few characters of the API key string, for helping identify the API key.
apiKey.projectId string Yes The ID of the project that this API key grants access to. When this is unset, the API key grants access to all projects in the team.
