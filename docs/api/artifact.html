create

POST /v8/artifacts/events

Operation ID: recordEvents.

Authentication: bearer token (bearerToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | x-artifact-client-ci | header | string | No | The continuous integration or delivery environment where this artifact is downloaded. | | x-artifact-client-interactive | header | integer | No | 1 if the client is an interactive shell. Otherwise 0 | | teamId | query | string | No | The Team identifier to perform the request on behalf of. | | slug | query | string | No | The Team slug to perform the request on behalf of. |

Request body

application/json

Property Type Required Description
[].duration number No The time taken to generate the artifact. This should be sent as a body parameter on HIT events.
[].event enum: HIT, MISS Yes One of HIT or MISS. HIT specifies that a cached artifact for hash was found in the cache. MISS specifies that a cached artifact with hash was not found.
[].hash string Yes The artifact hash
[].sessionId string Yes A UUID (universally unique identifer) for the session that generated this event.
[].source enum: LOCAL, REMOTE Yes One of LOCAL or REMOTE. LOCAL specifies that the cache event was from the user's filesystem cache. REMOTE specifies that the cache event is from a remote cache.

Responses

200: Success. Event recorded
400: One of the provided values in the request body is invalid. One of the provided values in the headers is invalid
401: The request is not authorized
402: The account is missing a payment so payment method must be updated
403: The customer has reached their spend cap limit and has been paused. An owner can disable the cap or raise the limit in settings. The Remote Caching usage limit has been reached for this account for this billing cycle. Remote Caching has been disabled for this team or user. An owner can enable it in the billing settings. You do not have permission to access this resource
