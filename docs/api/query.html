create

POST /v2/observability/query

Operation ID: createObservabilityQuery.

Authentication: not required.

Request body

application/json

Property Type Required Description
aggregation string No Aggregation function to apply. Some aggregations require a dimension: use <agg>/<dimension>, for example unique/visitor_id.
bucketTimezone string No IANA timezone (for example Europe/Paris) used only to align calendar buckets (1d/1mo) to that zone's day/month boundaries. startTime/endTime and all output timestamps are always UTC. No effect on sub-day granularities.
endTime string No End timestamp
filter string No Filter to apply to the query. JSON dimensions support nested refs, for example event_data/checkout_step eq 'payment'. Nested keys containing characters that OData cannot parse as an identifier, such as '-', spaces, quotes, or '/', must be wrapped in single quotes (escape embedded single quotes by doubling them), for example flags/'enable-comments-view' eq true or event_data/'some property''s/value' eq true.
granularity object No Time bucket size
groupBy array of string No Dimensions to group results by. JSON dimensions support nested refs, for example event_data/checkout_step. Nested keys containing characters that OData cannot parse as an identifier, such as '-', spaces, quotes, or '/', must be wrapped in single quotes (escape embedded single quotes by doubling them), for example flags/'enable-comments-view' or event_data/'some property''s/value'.
limit number No Maximum number of results
metric string Yes Metric id
orderBy string No Rollup column to order grouped results by. Use the generated rollup key for the requested metric and aggregation. Defaults to the query engine count rollup.
orderDirection enum: asc, desc No Direction to order grouped results by. Defaults to desc.
scope object Yes Owner or project scope for the query
startTime string No Start timestamp
