create

POST /v9/projects/{idOrName}/custom-environments

Operation ID: createCustomEnvironment.

Authentication: bearer token (bearerToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | idOrName | path | string | Yes | The unique project identifier or the project name | | teamId | query | string | No | The Team identifier to perform the request on behalf of. | | slug | query | string | No | The Team slug to perform the request on behalf of. |

Request body

application/json

Property Type Required Description
branchMatcher object No How we want to determine a matching branch. This is optional.

copyEnvVarsFrom string No Where to copy environment variables from. This is optional.
description string No Description of the custom environment. This is optional.
slug string No The slug of the custom environment to create.
