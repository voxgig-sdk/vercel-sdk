GET /v2/connect/connectors

Operation ID: listConnectors.

Authentication: bearer token (bearerToken).

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | limit | query | integer | No | Maximum number of connectors to return. Defaults to 20. | | cursor | query | string | No | Cursor from pagination.next on the previous response. | | projectId | query | string | No | Return only connectors connected to this project. | | search | query | string | No | Search connector names, UIDs, and services. | | type | query | string | No | Comma-separated connector types: slack, discord, github, linear, linq, salesforce, sendblue, snowflake, snowflake-wif, microsoft-entra, api-key, photon, oauth, or custom. | | service | query | string | No | Comma-separated provider or service identifiers. | | sort | query | enum: name, createdAt, updatedAt | No | Sort by name in ascending order, or by creation or update time in descending order. | | teamId | query | string | No | The team ID that scopes the request. Do not send it with slug. If both are omitted, Vercel uses the team associated with the token or the authenticated user's default team. The request returns 401 if no team can be selected. | | slug | query | string | No | The team slug that scopes the request. Do not send it with teamId.
