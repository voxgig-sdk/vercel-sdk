create

POST /v1/networking/privatelink/endpoints

Operation ID: createPrivateLinkEndpoint.

Authentication: bearer token (bearerToken).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | teamId | query | string | No | The Team identifier to perform the request on behalf of. | | slug | query | string | No | The Team slug to perform the request on behalf of. |

Request body

application/json

Property Type Required Description
awsServiceName string Yes The name of the AWS VPC endpoint service to connect to. Its AWS region is read from the name; when that region differs from the one behind vercelRegion, the service must allow cross-region access.
enablePrivateDns boolean No Whether to resolve the endpoint service through its private DNS names, which are then returned in privateDnsNames. Defaults to false, in which case the endpoint is reachable through the DNS names in awsDnsEntries.
name string Yes The name of the PrivateLink endpoint, used as its label in the Vercel dashboard.
projectId string Yes The project ID to create the PrivateLink endpoint for.
vercelRegion string Yes The Vercel region to provision the endpoint in. Advanced Networking must be enabled for the project in that region. The endpoint service itself may live in another AWS region.

Responses

201: The PrivateLink endpoint was created and is being provisioned

application/json

Property Type Required Description
awsDnsEntries array of string No The regional DNS names assigned to the endpoint by AWS. Use these to reach the service when private DNS is not enabled.
awsServiceName string Yes The AWS VPC endpoint service the endpoint connects to.
createdAt number Yes Timestamp in milliseconds since the UNIX epoch for when the endpoint was created.
endpointId string Yes The unique identifier of the PrivateLink endpoint.
name string Yes The name of the PrivateLink endpoint, shown in the Vercel dashboard.
privateDnsNames array of string No The private DNS names of the endpoint service, populated when private DNS is enabled for the endpoint.
projectId string Yes The identifier of the project the PrivateLink endpoint belongs to.
status enum: available, creating, deleting, failed, pending-acceptance, provisioning, ... Yes The current state of the endpoint. - creating: the endpoint is being created. - pending-acceptance: waiting for the endpoint service owner to accept the connection. Only occurs for services that require manual acceptance. - provisioning: the connection was accepted and AWS is finishing setup. - available: the endpoint is fully provisioned and ready to use. - rejected: the endpoint service owner rejected the connection. - failed: the endpoint could not be provisioned. - deleting: the endpoint is being deleted.
statusMessage string No A human-readable explanation of why the endpoint could not be provisioned. Only set when status is failed, and absent for every other status including rejected, since AWS does not report a rejection reason.
teamId string Yes The identifier of the team that owns the PrivateLink endpoint.
updatedAt number Yes Timestamp in milliseconds since the UNIX epoch for when the endpoint was last updated.
vercelRegion string Yes The Vercel region the endpoint is provisioned in.
vpcEndpointId string No The identifier of the underlying AWS VPC endpoint. Absent until AWS has created the endpoint.
400: One of the provided values in the request body is invalid
